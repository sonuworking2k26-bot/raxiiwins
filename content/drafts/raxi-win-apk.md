## Before you download

1. Confirm you intended to install an app at all — browser play is often enough.
2. Prefer a download button on a host you already trust over a file forwarded in chat.
3. Check spelling of the domain and whether HTTPS looks normal.
4. Note approximate size; tiny “full game” files are often fakes.
5. Read [scam checklist](/guides/scam-checklist) if the page promises guaranteed wins.

## Android install steps

1. Download only from the source you verified.
2. Allow install from that one browser/file manager when Android asks — turn the permission off again after.
3. Open the APK, review the app name, then install.
4. Launch → [login](/raxi-win-login) or [Register](/raxi-win-register).
5. Update later from the **same** trusted source, not random mirrors.

## Permission red flags

A colour / crash game rarely needs:

- Read all SMS
- Accessibility “full control”
- Contacts upload
- Install other apps

If those appear, stop and uninstall.

## Hack and mod APKs

Packages labelled unlock, auto-win, predictor, or H4CK are a common malware path. They do not change fair round math; they often steal logins. Stick to clean builds or browser access.
