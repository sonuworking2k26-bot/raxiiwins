# Raxi Win scam checklist

Use this list before you [Register](/raxi-win-register), [login](/raxi-win-login), deposit, or install any [APK](/raxi-win-apk). **raxiiwins.com** never asks for your OTP, password or UPI PIN.

## Red flags

| Flag | Why it matters |
|------|----------------|
| Pay a person to “activate” register | Real signup should not need that |
| Guaranteed colour / Aviator tips for a fee | Chance games cannot be sold as sure |
| Asks for UPI PIN to “receive” winnings | PIN only sends money |
| Remote access app “for KYC” | Full device takeover risk |
| Lookalike domain | One wrong letter steals logins |

---

## OTP and support tricks

- Real support does not need your SMS code in WhatsApp.
- Codes expire — pressure to “send now” is a tactic.
- Fake “security team” accounts clone logos; check handles carefully.

---

## Fake downloads

- Hack / mod / unlock APKs
- Files only shared as anonymous Drive links
- Apps demanding SMS + accessibility together

Prefer browser play when unsure. See [APK guide](/raxi-win-apk).

---

## Link checks

1. Type or open from a bookmark you saved after a good session.
2. Read the full host spelling.
3. Distrust ads that scream “official” without a clear company trail.
4. Compare screens to our [Register](/raxi-win-register) and [login](/raxi-win-login) screenshots — layout clones exist.

---

## If you already shared something

1. Change the password on the real host if you still can.
2. Contact your bank/UPI app if a PIN or QR payment was involved.
3. Stop chatting with the scammer account.
4. Do not send “verification” fees to recover funds — that is usually round two.
